# Быстрая справка по командам Make

## Основные команды
| Команда | Описание |
|---------|----------|
| `make help` | Показать справку |
| `make up` | Запустить контейнеры |
| `make down` | Остановить контейнеры |
| `make restart` | Перезапустить контейнеры |
| `make status` | Статус контейнеров |
| `make logs` | Показать логи |

## Работа с данными
| Команда | Описание |
|---------|----------|
| `make seed-data` | Заполнить тестовыми данными |
| `make init` | Полная инициализация (up + seed-data) |
| `make backup` | Создать резервные копии |

## Очистка и пересоздание
| Команда | Описание |
|---------|----------|
| `make clean` | Полная очистка (⚠️ данные будут потеряны) |
| `make rebuild` | Пересоздать контейнеры |

## Разработка
| Команда | Описание |
|---------|----------|
| `make dev-mysql` | Подключиться к MySQL |
| `make dev-postgres` | Подключиться к PostgreSQL |

## Подключение к базам данных

## Быстрый старт
```bash
make init     # Запуск + заполнение данными
make status   # Проверка статуса
make down     # Остановка
```
