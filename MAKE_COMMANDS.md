# Инструкция по командам Make для управления тестовыми базами данных

## Обзор

Данный Makefile предоставляет удобные команды для управления Docker контейнерами с тестовыми базами данных MySQL и PostgreSQL.

## Предварительные требования

- Установленный Docker и Docker Compose
- Установленный Make:
  - **Windows:** можно использовать chocolatey: `choco install make` или WSL2
  - **Linux/MacOS:** обычно предустановлен
- Рабочая директория должна содержать файл `docker-compose.yml`

### Особенности для Windows

Makefile адаптирован для работы в Windows CMD:
- Использует `timeout /t N /nobreak > nul` вместо `sleep`
- Использует `if not exist` для проверки папок
- Команды даты адаптированы под Windows формат

## Основные команды

### `make help`
Показывает справку по всем доступным командам.
```bash
make help
```

### `make up`
Запускает контейнеры с базами данных в фоновом режиме.
- Ожидает 30 секунд для полной инициализации баз данных
- Выводит информацию о подключении к базам

```bash
make up
```

**Результат:**
- MySQL: доступен на localhost:3306
- PostgreSQL: доступен на localhost:5432
- Учетные данные: `testuser` / `testpass123`
- База данных: `test_db`

### `make down`
Останавливает все запущенные контейнеры.
```bash
make down
```

### `make restart`
Перезапускает контейнеры (остановка + запуск).
```bash
make restart
```

### `make status`
Показывает текущий статус всех контейнеров проекта.
```bash
make status
```

### `make logs`
Показывает логи контейнеров в режиме реального времени.
```bash
make logs
```
*Для выхода нажмите Ctrl+C*

## Команды работы с данными

### `make seed-data`
Заполняет обе базы данных демонстрационными данными из файлов:
- `mysql/seed/demo_data.sql` - данные для MySQL
- `postgres/seed/demo_data.sql` - данные для PostgreSQL

```bash
make seed-data
```

### `make init`
Выполняет полную инициализацию:
1. Запускает контейнеры (`make up`)
2. Ждет готовности баз данных
3. Заполняет демонстрационными данными (`make seed-data`)

```bash
make init
```

**Рекомендуется для первого запуска проекта.**

## Команды очистки и пересоздания

### `make clean`
Выполняет полную очистку:
- Останавливает и удаляет контейнеры
- Удаляет Docker тома (данные баз данных)
- Очищает неиспользуемые Docker ресурсы

```bash
make clean
```

⚠️ **Внимание:** Все данные в базах будут потеряны!

### `make rebuild`
Пересоздает контейнеры с нуля:
1. Выполняет полную очистку (`make clean`)
2. Пересобирает образы без кэша
3. Запускает контейнеры (`make up`)

```bash
make rebuild
```

## Команды для разработки

### `make dev-mysql`
Открывает интерактивную сессию MySQL в контейнере.
```bash
make dev-mysql
```

### `make dev-postgres`
Открывает интерактивную сессию PostgreSQL в контейнере.
```bash
make dev-postgres
```

### `make backup`
Создает резервные копии обеих баз данных в папке `backups/`:
- `mysql_backup_YYYYMMDD_HHMMSS.sql`
- `postgres_backup_YYYYMMDD_HHMMSS.sql`

```bash
make backup
```

## Типичные сценарии использования

### Первый запуск проекта
```bash
make init
```

### Ежедневная работа
```bash
# Запуск
make up

# Остановка в конце дня
make down
```

### Проблемы с контейнерами
```bash
# Перезапуск
make restart

# Или полное пересоздание
make rebuild
```

### Очистка после работы
```bash
make clean
```

### Проверка статуса и логов
```bash
# Статус
make status

# Логи
make logs
```

## Устранение неполадок

### Контейнеры не запускаются
1. Проверьте статус: `make status`
2. Посмотрите логи: `make logs`
3. Попробуйте пересоздать: `make rebuild`

### Порты заняты
Убедитесь, что порты 3306 (MySQL) и 5432 (PostgreSQL) не используются другими приложениями.

### Проблемы с данными
Выполните полную очистку и инициализацию:
```bash
make clean
make init
```

### Права доступа (Linux/MacOS)
Убедитесь, что у пользователя есть права для выполнения Docker команд или используйте `sudo make <command>`.

## Дополнительная информация

- Все команды безопасны для многократного выполнения
- Команды `clean` и `rebuild` требуют подтверждения действий
- Логи контейнеров сохраняются до их удаления
- Резервные копии создаются с временными метками для уникальности
