# Инструкция по командам Make

Данный файл содержит описание всех доступных команд make для управления тестовыми базами данных Docker.

## 🚀 Основные команды

### Запуск и управление контейнерами

| Команда | Описание | Особенности |
|---------|----------|-------------|
| `make start` | Запуск контейнеров баз данных | Автоматически создает сеть `shared_db_network`, ожидание 45 сек |
| `make down` | Остановка контейнеров | Сохраняет данные в volumes |
| `make stop` | Остановка без удаления контейнеров | Более мягкая остановка |
| `make remove` | Удаление остановленных контейнеров | Данные в volumes сохраняются |
| `make restart` | Перезапуск контейнеров | `down` + `start` |

### Полная инициализация и управление данными

| Команда | Описание | Использование |
|---------|----------|---------------|
| `make init` | Полная инициализация | `start` + автоматическое заполнение данными |
| `make seed-data` | Заполнение баз данных демо-данными | Заполняет обе базы тестовыми данными |
| `make clean` | Полная очистка | Удаляет контейнеры + volumes с данными |
| `make rebuild` | Пересборка с нуля | `clean` + `start` |

## 🔄 Команды пересоздания контейнеров

### Пересоздание отдельных сервисов

| Команда | Описание | Время ожидания |
|---------|----------|----------------|
| `make recreate-mysql` | Пересоздать только MySQL контейнер | 30 секунд |
| `make recreate-postgres` | Пересоздать только PostgreSQL контейнер | 30 секунд |
| `make recreate-all` | Пересоздать все контейнеры | С подтверждением |
| `make force-recreate` | Принудительное пересоздание | Без подтверждения |

### Особенности команд пересоздания:
- Данные сохраняются в Docker volumes
- `recreate-all` запрашивает подтверждение
- `force-recreate` выполняется без вопросов
- Автоматическое ожидание инициализации БД

## 📊 Мониторинг и диагностика

| Команда | Описание | Вывод |
|---------|----------|-------|
| `make status` | Статус контейнеров | Список запущенных контейнеров |
| `make logs` | Логи контейнеров | Реальное время (Ctrl+C для выхода) |
| `make stats` | Статистика по данным | Количество записей в таблицах |
| `make test-connections` | Проверка подключений | Тест доступности обеих БД |

## 💾 Резервное копирование и восстановление

| Команда | Описание | Расположение файлов |
|---------|----------|-------------------|
| `make backup` | Создание резервных копий | Папка `backups/` |
| `make restore` | Восстановление из backup | Интерактивный выбор файла |

### Формат backup файлов:
- `mysql_backup_YYYYMMDD_HHMMSS.sql`
- `postgres_backup_YYYYMMDD_HHMMSS.sql`

## 🔌 Доступ к базам данных

### CLI подключения

| Команда | Описание | Требования |
|---------|----------|------------|
| `make mysql-cli` | MySQL командная строка | Контейнер должен быть запущен |
| `make postgres-cli` | PostgreSQL командная строка | Контейнер должен быть запущен |

### Shell доступ к контейнерам

| Команда | Описание | Оболочка |
|---------|----------|----------|
| `make shell-mysql` | Bash в MySQL контейнере | `/bin/bash` |
| `make shell-postgres` | Bash в PostgreSQL контейнере | `/bin/bash` |

**Выход из контейнера:** команда `exit`

## 🌐 Управление сетью

| Команда | Описание | Автоматизация |
|---------|----------|---------------|
| `make create-network` | Создать сеть `shared_db_network` | Автоматически при `start` |
| `make remove-network` | Удалить сеть | Останавливает контейнеры |
| `make network-info` | Информация о сети | Статус, подключения, примеры |

### Сетевые возможности:
- **Сеть**: `shared_db_network`
- **Доступ по именам**: `mysql:3306`, `postgres:5432`
- **Внешние контейнеры**: могут подключиться к сети
- **Автосоздание**: сеть создается автоматически

## 📖 Справочная информация

| Команда | Описание |
|---------|----------|
| `make help` | Полная справка по всем командам |

## 🔄 Типичные сценарии использования

### Быстрый старт с данными
```bash
make init          # Запуск + заполнение данными
```

### Разработка с чистыми базами
```bash
make start         # Только запуск контейнеров
```

### Очистка и пересоздание
```bash
make clean         # Полная очистка
make init          # Новый старт с данными
```

### Диагностика проблем
```bash
make status        # Проверить состояние
make logs          # Посмотреть логи
make test-connections  # Проверить подключения
```

### Работа с данными
```bash
make backup        # Сохранить данные
make restore       # Восстановить данные
make stats         # Посмотреть статистику
```

### Доступ для отладки
```bash
make mysql-cli     # MySQL интерфейс
make shell-mysql   # Полный доступ к контейнеру
```

## ⚠️ Важные замечания

### Времена ожидания:
- `start`: 45 секунд (полная инициализация)
- `recreate-mysql/postgres`: 30 секунд
- `init`: 15 секунд перед заполнением данных

### Подтверждения:
- `clean`: Требует подтверждения (удаление данных)
- `recreate-all`: Требует подтверждения
- `force-recreate`: Без подтверждения

### Автоматизация:
- Сеть создается автоматически при `start`
- Volumes создаются автоматически
- Инициализация БД происходит автоматически

### Данные:
- Сохраняются в Docker volumes
- Переживают пересоздание контейнеров
- Удаляются только командой `clean`

## 📝 Примеры команд

```bash
# Стандартный рабочий цикл
make start         # Запуск
make seed-data     # Заполнение данными
make mysql-cli     # Работа с MySQL
make down          # Остановка

# Полная инициализация одной командой
make init

# Диагностика и мониторинг
make status && make stats && make test-connections

# Резервное копирование
make backup && make clean && make restore

# Сетевая информация
make network-info
```
