# Тестовые базы данных - Краткое руководство

## Что создано

✅ **Два Docker контейнера:**
- MySQL 8.0 на порту 3306
- PostgreSQL 15 на порту 5432

✅ **Разные схемы данных:**
- MySQL: таблица `clients` (корпоративные клиенты РФ)
- PostgreSQL: таблица `users` (международные IT-специалисты)

✅ **Демо данные:**
- MySQL: 15 записей российских B2B клиентов
- PostgreSQL: 15 записей IT-пользователей со всего мира

✅ **Управление проектом:**
- Makefile (для Linux/Mac/Windows с Make)
- run.bat (для Windows без Make)
- Прямые docker-compose команды

## Быстрый запуск

### Windows (без Make)
```cmd
run.bat up        # Запуск
run.bat seed-data # Заполнение данными
run.bat status    # Проверка статуса
```

### С Make
```bash
make up           # Запуск
make seed-data    # Заполнение данными
make status       # Проверка статуса
```

## Подключение

### MySQL
```
Host: localhost:3306
User: testuser
Password: testpass123
Database: test_db
```

### PostgreSQL
```
Host: localhost:5432
User: testuser  
Password: testpass123
Database: test_db
```

## Внешний доступ

Базы данных доступны не только через localhost, но и по внешнему IP адресу машины на тех же портах (3306 и 5432).

## Особенности

- **Постоянные данные** - сохраняются в Docker volumes
- **Автоинициализация** - таблицы создаются при первом запуске
- **Уникальные данные** - схемы и данные в базах кардинально отличаются
- **Готовность к тестированию** - сразу после запуска можно подключаться
